# Goals for SOLACE Garden

Garden should remain simple and useful for ordinary gardeners while allowing specialized functionality to be added without unnecessarily expanding the core application.

---

### Core purpose

Who Garden serves and which problems it solves.

### MVP

The smallest useful and coherent Garden application.

### Post-MVP

Valuable features that aren't needed for the first release.

### Initial data handling

What gets stored, where it lives, and how people access it during Phase 1.

### Future data handling

Local-first operation, synchronization, portability, privacy, and eventually household-hosted services.
